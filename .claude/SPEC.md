# Goal

Create a single-page React app that takes the markdown notes in timeline/timeline_entries/ and displays them in a vertical timeline. 

# Requirements

1. The project MUST be a React app
2. The project MUST be single-page
3. The user MUST be able to filter timeline entries by the YAML frontmatter tag: properties

# Implementation Decisions

 - each timeline/timeline_entries/ note SHOULD be a distinct component
 - all of the YAML frontmatter tag: properties SHOULD be collected for easy reference

# Chapter 5
Page 24
Phases of TDD: 
 1. Write a test
 2. Make it compile
 3. Run it to ensure it fails
 4. Make the test pass (with an implementation)
 5. Remove duplication 
"The different phase have different purposes ... The first 3 phases need to go by quickly so we can get to a known state with a new functionality ... here speed trumps design for a brief moment"

Page 25
On duplication: duplication can occur in tests (copying existing test logic) as well as in the code itself (copying implementation logic), and there can be duplication between test and code (this is test-implementation "coupling").

# Chapter 6

Page 29
In the face of inadequate tests: 
"When you don't have enough tests, you are bound to come across refactoring that are not covered by tests. ... What do you do? ... Write the tests you wish you had."

INSIGHT: the purpose of tests is to make refactoring safe. The only redactors that are "safe" are those that modify code which is covered by tests that can be relied on to fail if the tester code's behavior changes.

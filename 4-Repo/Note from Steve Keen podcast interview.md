# 1-26-25
Today I listened to the [Escaped Sapiens podcast #65](https://youtu.be/Ma_TiVNa9wE?si=JHAM0gMpS6xN7CSm) featuring economist Steve Keen, where Keen is posed the question "is economics a science" and responds "no". In this podcast Keen points out a number of issues with mainstream (Neoclassical) economics, which he claims was founded/created by Paul Samuelson, which after only this past week getting back into reading economics I myself have run into, but have not been able to articulate. Keen also references other economists/thinkers that we should look into. What follows is a list of interesting takeaways from the podcast: 
 - read/listen to more of Keen's own work
 - Keen suggests studying [System Dynamics](https://mitsloan.mit.edu/faculty/academic-groups/system-dynamics/about-us)  as opposed to Economics
 - look into Keen's economic analysis software package called Minsky
 - American businessman/venture capitalist Richard Vague on private debt
 - Hungarian economist Janos Kornai on Soviet Communism vs. Western Capitalism
 - book The Limits to Growth, 1972

The idea is not to come up with some all encompassing system of morality that provides explicit and precise answers to specific questions. This is not possible I don't think, if it were we would have such a system by this point. 

No, the idea is rather to assemble a set of tools and metrics for assessing whether a given practice or behavior or law (A) serves the purposes of, or is in line with some existing or imagines system of morality (B), which itself is simply a set of corresponding stated beliefs. The idea is to dispassionately assess the extent to which (A) serves and/or is consistent with (B).

Advocating for such a system makes me some combination of a Metaethical Coherentist, as well as a Moral Subjectivist. Metaethical Coherentism requires that moral beliefs "belong to a coherent system, [where] coherence is taken to involve three components: logical consistency, explanatory relations, and various inductive (non-explanatory) relations", the system holding itself up like a reciprocal frame self-supporting structure. The system must support itself because I do not believe there is any explicit moral foundation upon which any system can rest. Moral Subjectivism says that each individual erects and maintains such a system within themselves, using pieces learned or borrowed from wherever, and the morality or immorality of ones actions depends on the extent to which said actions "cohere" with that internal system.  

It is possible that this absence of a foundation is an artifact of our reliance on language to discuss morality and moral beliefs. As John Hasnas makes clear, neutral language impervious to interpretation is not possible to achieve, thus making discussions of morality as slippery as they have appeared to be for as long as we have been having them.

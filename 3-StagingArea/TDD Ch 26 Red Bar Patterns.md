# Chapter 26

Page 134
"Each test should represent one step towards your overall goal. ... A program grown from tests like this can appear to be written 'top-down' and can also appear to be written 'bottom-up'. Neither really describes the process helpfully. ... Growth implies a kind of self-similar feedback loop in which the environment affects the program and the program affects the environment. If we need to have a direction in our metaphor then 'known-to-unknown' is a helpful description. Put these two together and we have programs growing from known to unknown."
